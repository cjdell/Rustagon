Rustagon Firmware Tool

Click the "Connect" button to begin. Please specify "Erase device" when prompted.

If you're having trouble installed the firmware, force the badge into DFU mode using the "boop/reboop" buttons labelled on the back:

  1. Hold in "boop" button
  2. Press and release "reboop" button
  3. Release "boop" button

After firmware update is complete. You may need to press the "reboop" button.

First boot

Upon first boot you should see the Rust logo. The firmware will attempt to format the filesystem using littlefs. This takes a few seconds.

The badge will create a WiFi AP called Rustagon. Connect to this network on a device. If the captive portal doesn't automatically open, manually go to http://192.168.1.1 in a browser.

Once connected to your home WiFi network you can reach the badge again at http://rustagon.local in your browser of choice.

Tip: Use the "boop" button to quit apps.

Please see the Git repo for usage instructions.
